# MyProject

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 15.2.11.

## Requirements

The following tools must be installed to run this application:

| Tool | Version |
|------|---------|
| [Node.js](https://nodejs.org/) | 18.x or later |
| [npm](https://www.npmjs.com/) | 9.x or later |
| [Angular CLI](https://angular.io/cli) | 15.2.11 |
| [TypeScript](https://www.typescriptlang.org/) | ~4.9.4 |

> **Backend:** A Node.js backend server must be running on `http://localhost:3000`.
> The frontend dev server proxies `/api` and `/users` requests to it.

### Install Angular CLI globally

```bash
npm install -g @angular/cli@15.2.11
```

### Install project dependencies

```bash
npm install
```

## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.
